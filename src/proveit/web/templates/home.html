Five stages, and which model does what

Deterministic code decides what it can. Models handle what code cannot, and every verdict has to show its receipts.

Grounding

No model

Every file, line, function, commit, quote and version the report cites is checked against curl at the revision it targets.

Claims

Nemotron 3 Nano · reasoning off

Turns the report into checkable claims: the flaw, how an attacker triggers it, what it does.

Evidence

git + Tavily

Pulls the real functions, line-numbered, plus the release version when master has changed. Tavily fetches dependency docs the report quotes.

Judgment

Nemotron 3 Ultra · reasoning on

Rules on each claim against the code it was shown, applying curl's own policy on what is not a security issue.

Receipts

No model

Citations must point at code the judge saw, quotes must be verbatim. A verdict without receipts becomes "needs a human".
